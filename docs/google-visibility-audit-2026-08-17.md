## معالجة ظهور نطاق Manus وتحسين الصفحات الأساسية

أظهرت اللقطة التي أرسلها المالك نتيجةً قديمة على نطاق Manus مختلف (`al-eshraqa.manus.space`) وليست على النطاق الرسمي `al-eshraqa.co`. أكّد فحص هذا النطاق القديم وجود بيانات اتصال غير مطابقة للموقع الحالي؛ لذلك لا يُعامل كنسخة رسمية ولا يُستخدم رابطًا قانونيًا أو مرجعًا لبيانات الشركة.

نُفذت التحسينات التالية في الموقع الرسمي فقط، دون تعديل DNS أو بيانات الاتصال:

| التحسين | الهدف |
| --- | --- |
| بيانات منظمة موحدة من أنواع `Organization` و`WebSite` و`WebPage` و`AboutPage` | إعطاء Google إشارة صريحة إلى اسم الشركة ورابطها الرسمي وصفحة «عنّا». |
| `canonical` و`hreflang` خادميان على `https://al-eshraqa.co` | تثبيت الوجهة القانونية العربية لكل صفحة عامة. |
| عنوان ووصف أوضحان لصفحة «عن شركة الإشراقة للتنظيف والصيانة ونقل العفش» | تحسين فهم موضوع الصفحة عند فهرستها وعند إعادة كتابة عنوان النتيجة. |
| روابط داخلية إضافية إلى صفحة «عن شركة الإشراقة» والخدمات والأدلة والأسئلة الشائعة | تقوية اكتشاف الصفحات الأساسية ضمن الموقع. |

> هذه التحسينات لا تعيد كتابة نتائج Google فورًا؛ قد يحتفظ Google بلقطة قديمة أو يعيد صياغة العنوان، ويحتاج إلى إعادة الزحف ثم تقييم الإشارات الجديدة. يلزم فحص النطاق الرسمي فقط عند طلب الفهرسة أو قياس الظهور.
