# تحقق إصلاح إجابات مساعد الإشراقة

تمت المراجعة في 18 أغسطس 2026 لشكوى ظهور إجابة عامة ومشوّهة لسؤال «كيف أنظف بيتي؟».

- يعالج مسار `ai.chat` هذا السؤال الآن بإجابة إجرائية ثابتة قبل استدعاء النموذج، تتضمن ترتيب العمل والتنظيف من الأعلى إلى الأسفل والتنبيه من خلط مواد التنظيف.
- تُزال روابط Markdown وعناوين URL من النص المعروض للمستخدم؛ تظهر روابط الموقع كبطاقات وروابط واجهة مستقلة بدل مسارات تقنية داخل الجواب.

- اجتازت اختبارات المشروع وبناء الإنتاج بعد التغيير، وأضيفت تغطية لاختبار الإجابة العملية وتنسيقها.
